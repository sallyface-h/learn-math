## Installation

ProviderError is available through [CocoaPods](http://cocoapods.org). To install
it, simply add the following line to your `Podfile`:

```ruby
source 'git@github.com:Nuevo-Mundo/Emperor_iOS.git'
source 'https://github.com/CocoaPods/Specs.git'
platform :ios, '9.0'

target <Your Target Name> do
	use_frameworks!
    pod 'ProviderError'
end
```

Then, run the following command:

```bash
$ pod install
```
