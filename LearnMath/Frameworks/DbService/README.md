## Installation

DbService is available through [CocoaPods](http://cocoapods.org). To install
it, simply add the following line to your `Podfile`:

```ruby
source 'https://github.com/vjieshao/Arithmetic_Specs.git'
source 'https://github.com/CocoaPods/Specs.git'
platform :ios, '9.0'

target <Your Target Name> do
	use_frameworks!
    pod 'DbService'
end
```

Then, run the following command:

```bash
$ pod install
```
